# QR Here

A free online QR code scanner and generator that works directly in your browser.

## Website

https://qrhere.online/

## Features

- Scan QR codes using your camera
- Scan QR codes from uploaded images
- Generate QR codes from text and URLs
- Download generated QR codes
- Works directly in the browser
- No app installation required

## Tech Stack

- React
- TypeScript
- Vite
