1. EXECUTIVE SUMMARY & OUR GOAL
================================================================================
QR Here (https://qrhere.online) is a fast, free, privacy-first web utility for 
scanning and generating QR codes and barcodes directly inside modern web 
browsers.

OUR GOAL:
To become the world's most trusted, ultra-responsive, zero-friction QR code and 
barcode platform on the web.

Key Pillars of Our Goal:
1. Universal Accessibility: No app downloads, no account registrations, no 
   subscriptions, no forced sign-ups, and no paywalls.
2. Uncompromising Privacy: 100% of video decoding, barcode parsing, image 
   analysis, and vector QR rendering happens client-side in the user's browser 
   memory. Scanned data, camera streams, and personal credentials NEVER touch 
   a remote server.
3. Top-Tier Performance: Sub-second load times, smooth 60fps camera scanning, 
   instant vector generation, and pristine Core Web Vitals scores (LCP < 1.2s, 
   INP < 50ms, CLS = 0).
4. Permanent Free Utility: While competitors bait users with "dynamic" QR codes 
   that expire after 14 days and demand monthly fees, QR Here creates permanent, 
   un-expiring static QR codes with vector SVG/PNG/PDF downloads that work forever.
5. High Organic Search Footprint: Deep technical SEO architecture ranking 
   across commercial intent queries for scanning, creating, and specialized 
   formats (Wi-Fi, WhatsApp, vCard, Barcodes).

4. SOFTWARE ARCHITECTURE
================================================================================

4.1. HIGH-LEVEL ARCHITECTURAL PATTERN
-------------------------------------
- Architecture: Single Page Application (SPA) built with React 19 and Vite 6.
- Routing: Declarative client-side routing via React Router DOM v7.
- Code Splitting: Route-level lazy loading (`React.lazy` + `Suspense`) ensures 
  the initial bundle is razor-thin (~90KB gzipped). Non-homepage pages (generator, 
  blogs, scanner variants) are downloaded on demand.
- Component Design: Pure functional components with custom hooks (`useTheme`, 
  `useOnlineStatus`, `usePWAInstall`).
- Styling: Tailwind CSS v4 with unified design tokens, dark mode classes (`dark:`), 
  and zero custom external CSS files.

4.2. CLIENT-SIDE RENDERING & ZERO-PERSISTENCE PRIVACY MODEL
------------------------------------------------------------
- 100% Client-Side Execution: Unlike server-rendered QR generators that save images 
  to AWS S3 or pass user input to backend endpoints, QR Here processes everything 
  in the client's V8 engine / browser runtime.
- Zero Persistence: Camera video streams are piped strictly into an in-memory 
  HTML5 `<video>` element. Frames are sampled onto an off-screen HTML5 `<canvas>`. 
  Once parsed, pixel buffers are immediately released. When the user stops the camera 
  or leaves the tab, `MediaStreamTrack.stop()` shuts down the camera hardware.

4.3. STATE MANAGEMENT & DATA FLOW
---------------------------------
- Generator State: Clean, typed immutable design state model (`QRDesignState`) 
  managing payload fields, styling (dot patterns, eye patterns, colors, gradients), 
  logo settings, and frame parameters.
- Separation of Concerns:
  * `src/services/qr/generator.service.ts`: Reed-Solomon encoding and matrix calculation.
  * `src/services/qr/advanced-renderer.service.ts`: Vector SVG construction and frame math.
  * `src/services/barcode/barcode-scanner.service.ts`: Multi-format barcode parsing.
  * `src/services/camera/camera.service.ts`: Hardware camera lifecycle, permissions, and torch.

4.4. VIDEO & CANVAS FRAME PROCESSING PIPELINE
---------------------------------------------
- Camera Loop: Uses `requestAnimationFrame` with a 160ms throttle to prevent 
  CPU starvation while maintaining immediate responsiveness.
- Multi-Engine Decoding Pipeline:
  1. Tier 1 (Hardware Acceleration): If `window.BarcodeDetector` exists, decode 
     the video element directly on the device GPU/C++ layer (<5ms).
  2. Tier 2 (ZXing MultiFormat Reader): Scans canvas buffer across 1D/2D symbologies.
  3. Tier 3 (jsQR Engine): Specialized fast fallback for QR codes under tough angles.

4.5. OFFLINE PWA & SERVICE WORKER
---------------------------------
- Configured via `vite-plugin-pwa` with Workbox caching strategy.
- Web App Manifest: `/manifest.webmanifest` with responsive icons and shortcuts.
- Offline Capability: Core generator and scanner logic works 100% offline once cached.

9. SECURITY & PRIVACY MANDATE
================================================================================

9.1. QUISHING (QR PHISHING) & MALICIOUS URL DETECTION
- Scanned URLs pass through `src/utils/security/url.ts`.
- Deep Inspection Checks:
  * IP Address URLs: Flags raw IP addresses (e.g., http://192.168.1.1 or public IPs) 
    frequently used in malicious attacks.
  * Punycode / Homograph Attacks: Flags internationalized domain names (xn--) 
    used to spoof legitimate brands like paypal.com or google.com.
  * Insecure HTTP: Warns users if a destination URL lacks TLS encryption.
  * Embedded Credentials: Flags URLs with embedded user credentials (e.g., user:pass@domain).
  * BiDi Spoofing: Detects bidirectional override characters used to disguise file extensions.
  * Private / Local IP Warning: Detects intranet addresses to prevent SSRF-like local attacks.

9.2. ZERO DATA RETENTION ARCHITECTURE
- No databases (no SQL, no MongoDB, no Firestore).
- No user accounts, cookies, or sessions tracking personal data.
- Camera streams exist exclusively in device RAM for immediate frame decoding.
